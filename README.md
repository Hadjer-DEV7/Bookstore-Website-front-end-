WebSite Readers Heaven

A modern online bookstore inspired by elegant e-commerce designs, built with HTML and CSS.
Readers Heaven is a responsive bookstore landing page that transforms a classic online shop template into a beautiful book shopping experience.
The website features a clean interface, vibrant gradients, featured books, customer reviews, services, and a custom login page designed around a reading theme.

✨ Features:
- Beautiful bookstore landing page
- Featured book collection
- Customer reviews section
- Wishlist & shopping cart icons
- Services section (Fast Delivery, Easy Replacement, 24/7 Support)
- Modern login page
-Purple gradient UI with smooth hover effects
-Clean HTML & CSS code
